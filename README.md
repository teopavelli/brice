# Snake Game

Snake Game is a compact Python implementation of the classic arcade game.

The project separates rendering, gameplay logic and collision detection into independent modules. It uses the built-in Tkinter library, so no external dependencies are required.

## Features

- Classic snake gameplay
- Random food generation
- Score counter
- Collision detection
- Configurable board size
- Modular architecture

## Controls

- ↑ Move Up
- ↓ Move Down
- ← Move Left
- → Move Right

## Run

```bash
python main.py
```
